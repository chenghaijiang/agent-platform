# ADR-017：二期能力语义定界与一期施工序（审问收尾）

- 状态：已接受
- 日期：2026-11-14
- 关联：ADR-013（执行边界安全模型）、ADR-014、ADR-015、ADR-016
- 来源：grill-with-docs 审问第四轮裁决（Q19–Q22 按推荐接受）。本 ADR 为「统一智能工作台」审问的收尾裁决，设计树至此无未访问分支。

## 决策

1. **Subagent 权限 = 继承并收窄（Q19A）**：subagent（fresh messages[] 上下文隔离）的权限 = 父 Task 的 mode/owns/grants 交集，只可收窄不可放大；confirm 模式下 L2 工具仍触发审批卡片，决策冒泡给用户且对父子同时生效。上下文隔离 ≠ 权限隔离；「权限冒泡」即三期 Agent Teams 收件箱语义的前置实现。否决天然全量（spawn 即绕过 owns/审批的权限旁路）与独立声明（B 的体面版本）。
2. **Memory 存储 = PG + pgvector 同域（Q20A）**：新增 `agent_memories` 表（`user_id, profile_key, content, embedding(Vector), kind(episode/semantic), status`），复用入库 pgvector 管道与模型网关 embedding 能力位；consolidation 为定时任务对同 user 记忆做抽取合并。与 Q18 同一世界观修正：否决磁盘文件（多副本分裂）与独立向量库（Compose 单库形态不值得第二存储系统）。
3. **Worktree Isolation = 原地升级（Q21A）**：二期把 `workspaces/<task_id>/<repo>` 从「拷贝装载」升级为真 git worktree（共享主仓对象库 + 分支隔离），`WorktreeRecord(task_id, worktree_path, branch)` 落 PG；现有 `WorkspaceManager.allocate` 路径语义外推，零迁移。
4. **一期施工序 = 数据层先行（Q22A）**：alembic 迁移（`agent_profiles` + `chat_messages` + `agent_tasks.chat_session_id` + seed 双 profile）→ 后端桥接（SSE 信封、审批卡片端点、model_policy fallback 链）→ 前端工作台改造（智能体选择器、卡片渲染、会话侧栏）。UI 不做 mock 原型（信封 schema 已由 ADR-014/015 定死）。
